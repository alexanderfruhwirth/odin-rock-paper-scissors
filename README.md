# odin-rock-paper-scissors

This project is the third self-reliant exercise provided by The Odin Project open source curriculum.

## Expectations before starting the exercise

The task for this exercise is to create a Rock Paper Scissors game in JavaScript. The Odin Project strongly encourages following the problem-solving steps taught throughout their JavaScript Basics module. With this in mind, I expect to improve my problem-solving skills by making sure I understand the assignment before planning the steps required to solve it and eventually implementing the solution. This means dividing the task of creating a Rock Paper Scissors game into subtasks, writing pseudocode for the steps needed to complete each subtask and, finally, turning the pseudocode into JavaScript to finish the exercise.
